# 节日祝福（Festival Greetings）

关系导向的 AI 祝福贺卡助手——写好这句话，做成一张可分享的贺卡。

## 仓库结构

```
festival-greetings/
├── apps/
│   └── festival_greetings/    # Flutter App（Phase 4）
├── docs/
│   ├── product/
│   │   ├── 2026-09-03-节日祝福/   # 当前 PRD（主竞品：大福贺卡）
│   │   └── _archive/              # 归档文档
│   ├── prototype/
│   └── workflow/festival_greetings/
└── README.md
```

## MVP 闭环

选关系与场景 → AI 生成祝福语 → 套静态贺卡 → 保存相册 / 系统分享
