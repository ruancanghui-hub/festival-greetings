# 节日祝福 Root Tab 视觉锁定

## 共享壳层

| 项目 | 锁定值 |
|---|---|
| Root Tab 顺序 | 首页 / 创作 / 我的 |
| 导航形态 | 深墨蓝半透明纸感底栏；图标在上、中文标签在下；三等分 |
| 激活态 | 朱砂红 `#C84B3A` 图标与标签；其余为低饱和米金色 |
| 背景 | 深墨蓝纤维纸纹，月色暖光点缀 |
| Surface | 靛蓝哑光纸卡 + 米白信笺面；圆角约 20–28px |
| 文本 | 暖米白正文、米金辅助信息；标题使用具有书写感的中文展示字 |
| 角色 | 云笺仅作为小型陪伴锚点；两眼、一个头顶朱砂点、两翼、两脚、右上折角信笺与一枚朱砂圆印 |

## P0 页面映射

| Tab | 主要任务 | 关键内容 |
|---|---|---|
| 首页 | 两步进入创作 | 节日倒计时、六关系入口、模板推荐、AI 创作入口 |
| 创作 | 完成 AI 文案参数输入 | 关系、场景、风格、补充文字、生成主按钮、精选库降级入口 |
| 我的 | 复用已存内容 | 我的文案、收藏贺卡、隐私政策、关于、反馈 |

不包含广告、会员、登录、云同步、照片贴图、动态视频或社交 Feed。
