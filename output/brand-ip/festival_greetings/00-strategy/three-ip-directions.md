# 节日祝福 — 三条品牌 IP 方向

评分为 1–5 分，基于 PRD 的关系导向创作、静态贺卡分享与无广告不追踪定位；仅用于选择设计方向，不代表商标可注册性。

## A. 云笺 / Cloud Note（推荐）

**定位**：一只替你把心意送达的小信使。

- **形态与轮廓**：圆润的小云雀，身体为一枚折角信笺的水滴轮廓；左、右各一片短翼，头顶一枚朱砂色圆点，喙短小。小尺寸仍能读成「鸟 + 信笺」。
- **情感层与性格**：归属感与安全感；安静、体贴、懂分寸。说话简短、有留白，例如「这句刚刚好」。避免过度卖萌、说教或替用户表达私人承诺。
- **色彩与材质**：米白纸张为主体，朱砂红用于印记和主行动，松石绿作辅助，深墨蓝承载正文；哑光棉纸和轻微压纹。
- **标志道具**：一枚小红印章；可转化为进度、已保存、已分享的状态标记。
- **产品映射**：首页作为关系入口的轻引导；创作流程中由「信笺展开」表示文案生成；成卡时做角落印记而非大面积角色图。
- **内容与延展**：不同节日只变换信封纸纹与花枝，不改角色。适合「写给谁」「一句话心意」「今天适合送达」三类轻内容。
- **风险**：鸟类与信笺组合需保持独特的折角轮廓，避免泛化成普通小鸟；名称需要后续商标检索。

## B. 团圆团 / Reunion Orb

**定位**：把牵挂揉成一颗会发光的小圆子。

- **形态与轮廓**：一颗圆形糯米团，顶部有一片双叶芽，脸颊左右各一个浅金圆点；两只短手、无外露腿。轮廓极简、圆满。
- **情感层与性格**：归属感与庆祝感；热情、乐观、善于把节日气氛点亮。语气可更活泼，例如「这份心意，团团圆圆」。避免俏皮过量和食物拟人化的婴儿感。
- **色彩与材质**：暖糯白、柿子橙、桂花金、夜青；软陶与糯米纸感。
- **标志道具**：一粒桂花星；可用作收藏、节日倒计时和推荐模板的状态符号。
- **产品映射**：适合首页节日提示和空状态；在贺卡内仅做小印花，不干扰跨场景使用。
- **内容与延展**：春节、中秋、生日等节日都可用配件变化；更适合节日节点运营和贴纸表情。
- **风险**：节日感强，婚礼、客户问候等正式场景的可用性略弱；食品联想须避免影响产品的得体感。

## C. 留白鹿 / Blank Deer

**定位**：为郑重的心意留一处安静的空白。

- **形态与轮廓**：纤小梅花鹿，椭圆头、两只短耳、两支各两杈的极简鹿角，胸前一枚月牙形留白徽记；四肢完整而修长。
- **情感层与性格**：尊重与自我表达；从容、温柔、有审美判断。语气更克制，例如「留一点余白给心意」。避免玄学、悲伤、过度疏离。
- **色彩与材质**：雾粉、瓷白、墨绿、低饱和金；磨砂陶瓷与水彩纸。
- **标志道具**：月牙留白徽记；可转为文字字数指示、排版安全区和生成中的呼吸动画。
- **产品映射**：强化文案编辑、排版预览和正式场景（老师、客户、婚礼）；首页存在感较低，避免干扰用户直达创作。
- **内容与延展**：适合高质感静态模板、季节配色及微动画；能支撑「正式」「简短」风格。
- **风险**：小尺寸角与腿容易丢失，且节日热闹感较弱；需要严格控制角数与比例，确保不变成普通小鹿。

## 推荐与选择

推荐 **A「云笺 / Cloud Note」**：它把「写一句话、做一张卡、送给某个人」压缩进一个可辨识的鸟与信笺轮廓；既能服务温暖亲友场景，也不会压低婚礼、老师或客户祝福的得体感。
