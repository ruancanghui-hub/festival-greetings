# 节日祝福 — Phase 2 品牌 IP 简报

## 产品承诺

「关系导向的 AI 祝福贺卡助手——写好这句话，做成一张可分享的贺卡。」

用户先选接收对象与场景，再取得可编辑的祝福语，最后将文字合成为静态贺卡并保存或分享。品牌需要让这条流程感觉温暖、得体、轻盈，而不是像批量群发或节日营销。

## 设计边界

- 受众：18–45 岁、在节日或人生场景里向亲友致意的中文 iPhone 用户。
- MVP：首页 / 创作 / 我的三 Tab；AI 文案、精选库、静态模板、保存与系统分享。
- 视觉任务：帮助用户从「不知道怎么说」安心进入创作，并让成卡有仪式感。
- 气质：温暖、克制、有画面感；不幼态喧闹，不做强促销或春节限定品牌。
- 约束：仅简体中文；无广告、不追踪；不可使用第三方角色、商标、竞品的标识性美术。
- 非目标：短视频、照片贴图、会员、社交 Feed、账号体系。

## IP 在产品中的作用

IP 只承担陪伴、状态反馈与轻提示：在首页迎接、创作完成时庆祝、空状态和权限拒绝时安抚。贺卡模板本身仍以场景氛围和可读文案为主，避免角色压过祝福对象。
