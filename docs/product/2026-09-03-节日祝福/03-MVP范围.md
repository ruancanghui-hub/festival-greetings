# 节日祝福 MVP 范围

- 产品名：节日祝福
- 模式：深度访谈模式
- 平台：iOS 优先（iOS 16.6+）
- 目标用户：逢年过节需向亲友发送有仪式感中文祝福的成年 iPhone 用户
- 商业策略：MVP 完全免费无广告；架构预留会员订阅，P2 接入 StoreKit
- 版本：V1.1
- 日期：2026-09-03

## 1. 验证假设

**假设**：关系导向的 AI 文案叠静态贺卡，能让用户在约 1 分钟内完成「想到要祝福 → 做好一张图 → 发出去」，且「保存或分享贺卡」转化率高于仅复制文字。

- **用户**：18–45 岁节日祝福需求用户
- **干预**：关系入口 + AI 文案 + 24 套静态模板
- **期望行为**：首次会话至少 1 次 card_save 或 card_share
- **观察周期**：TestFlight 2 周，≥ 30 人

## 2. 目标用户

需要「有画面感」中文祝福、愿用系统分享发微信/相册的 iPhone 用户。排除：要批量群发短信者；强依赖短视频特效者（P1）。

## 3. In Scope

| 能力 | 最小可用形态 | 验收结果 |
|---|---|---|
| 关系+场景 AI 文案 | 6 关系 × 8 场景 × 4 风格 | 成功率 ≥ 95% |
| 精选文案库 | 8×10 条本地 | 离线可选文案 |
| 静态贺卡模板 | 8×3=24 套 | 均可预览合成 |
| 合成出图 | 文案渲染到模板 | P95 < 3s |
| 保存相册 | 用户触发时请求写入权限 | 授权后文件可见 |
| 分享图片 | Share Sheet | 取消无崩溃 |
| 我的模板/收藏 | 本地 CRUD | 重启保留 |
| 设置 | 隐私/关于/反馈 | 审核可过 |

## 4. Out of Scope

| 能力 | 原因 |
|---|---|
| 短视频/动态贺卡 | P1，工程量大 |
| 自定义照片贴图 | P1，读相册权限 |
| 搜索 / 节日提醒 | P1 |
| 会员 / 广告 | P2 / OUT |
| Android / 账号云同步 | 非 MVP |

## 5. 最小内容与数据对象

### 5.1 首发内容/配置规模

- 关系 6：父母、伴侣、朋友、同事/领导、老师、孩子
- 场景 8：春节、中秋、端午、元旦、生日、婚礼、圣诞、乔迁
- 风格 4：温暖、可爱、正式、简短
- 静态模板 24；精选文案 80
- 节日日历：公历 + 春节/端午/中秋农历换算

### 5.2 最小数据对象

| 对象 | 要点 | 存储 |
|---|---|---|
| CardTemplate | id, occasion, assetPath, textRect | Bundle |
| Greeting | id, occasion, text | Bundle JSON |
| GenerationRequest | recipient, occasion, style, hint? | 仅请求 |
| ComposedCard | localPath?, text, templateId, createdAt | 可选本地缓存 |
| Favorite / MyTemplate | 同前版语义 | 本地 DB |

### 5.3 必需后台能力

AI 代理（参数入、过滤后文案出）；无用户生成内容云库。

## 6. 关键页面

启动引导、首页、创作（参数/结果/选模板/预览）、祝福库列表与详情、我的、模板编辑、设置、系统权限弹窗。

## 7. 验收标准

### 7.1 产品闭环

3 分钟内：选「朋友·春节」→ 生成文案 → 选模板 → 预览 → 分享或保存。

### 7.2 功能与规则

AI P95 < 8s；合成 P95 < 3s；相册拒绝时分享仍可用。

### 7.3 稳定性与性能

冷启动 < 2s；TestFlight 无 P0 崩溃与数据丢失。

### 7.4 隐私、安全与合规

不追踪；隐私政策可访问；AI 过滤生效。

### 7.5 增长/效果验证

card_save + card_share 覆盖会话 ≥ 35%。

## 8. 工作包

| 包 | 范围 | 高风险 |
|---|---|---|
| W1 内容与模板资产 | 80 文案 + 24 模板 | 版权与设计品质 |
| W2 AI 代理 | 提示词与过滤 | 质量/成本 |
| W3 创作流 UI | 参数→文案→套卡 | 流程丝滑 |
| W4 渲染引擎 | 文本布局与导出 | 超长文案 |
| W5 相册与分享 | 权限与 Share Sheet | 权限拒绝路径 |
| W6 我的/设置 | 本地数据与合规页 | — |

## 9. 灰度发布

内部 3 日 → TestFlight 30 人 2 周 → P0 全过 → 中国区上架。

## 10. 后续扩张

P1 动态贺卡与贴图；P2 会员；R&D 语音/Widget。

## 11. 发布否决条件

- AI 或合成超时无降级
- 违规内容可见
- 无隐私政策或声明与实现不符（如暗含追踪）
- 模板/文案版权纠纷未清
- 相册主路径在授权用户下无法保存且无分享替代
