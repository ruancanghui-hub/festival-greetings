# 节日祝福 功能清单

- 产品名：节日祝福
- 模式：深度访谈模式
- 平台：iOS 优先（iOS 16.6+）
- 目标用户：逢年过节需向亲友发送有仪式感中文祝福的成年 iPhone 用户
- 商业策略：MVP 完全免费无广告；架构预留会员订阅，P2 接入 StoreKit
- 版本：V1.1
- 日期：2026-09-03

## 1. 优先级定义

| 标识 | 定义 |
|---|---|
| P0 / MVP | 完成首版价值闭环且通过发布门 |
| P1 | MVP 后第一个扩展版本 |
| P2 | 长期完整产品蓝图 |
| R&D | 需技术、证据或合规验证后才能承诺 |

## 3. 竞品基线

主竞品：[大福贺卡](https://apps.apple.com/cn/app/%E5%A4%A7%E7%A6%8F%E8%B4%BA%E5%8D%A1-%E6%96%B0%E5%B9%B4%E6%81%8B%E7%88%B1%E7%94%9F%E6%97%A5%E5%9C%A3%E8%AF%9E%E7%AD%89%E7%94%B5%E5%AD%90%E8%B4%BA%E5%8D%A1%E5%88%B6%E4%BD%9C/id1345185172)（App Store，2026-09-03）

| 模块 | 竞品已核实能力 | 本产品 MVP 态度 |
|---|---|---|
| 动态/短视频贺卡 | 一键生成并保存视频 | 推迟 P1；MVP 做静态图 |
| 节日主题模板 | 新年/生日/圣诞/婚礼等 | P0 保留静态模板形态 |
| 海量祝福语 | 上千条可选 | 精选库 + AI，不做「上千」规模承诺 |
| 自定义照片/素材 | 头像与素材贴图 | 推迟 P1 |
| 保存相册分享 | 本地珍藏与社交分享 | P0 对齐 |
| VIP 订阅 | 周/月/年，解锁模板去广告 | 推迟 P2 |
| 广告与追踪 | 隐私标签含追踪标识符 | **明确不做**（差异化） |

次要参考（已归档）：祝福短信助手 — AI 文字生成思路保留为差异化能力，不再作主竞品基线。

## 4. 用户特色

| 特色 | 解决的问题 | 依赖 | 风险 | 阶段 |
|---|---|---|---|---|
| 关系导向入口 | 不知从哪类模板开始 | Recipient 分类 | 分类过细 | P0 |
| AI 写卡上文案 | 模板文案撞词、不够走心 | 云端 LLM | 延迟/成本/审核 | P0 |
| 静态卡即可分享 | 动态视频门槛高 | 本地渲染 | 视觉弱于竞品 | P0 |
| 无广告不追踪 | 竞品广告体验差 | 本地优先架构 | 短期变现弱 | P0–P1 |

## 5. 公共基础与合规

- **账户**：MVP 无登录
- **权限**：保存贺卡需相册**写入**；读相册（贴图）P1；通知 P1
- **支付**：MVP 无 IAP；预留 FeatureGate
- **隐私**：不追踪、不读通讯录/短信；AI 仅传生成参数；对齐「不收集可识别用户数据」目标
- **内容安全**：AI 输出服务端过滤
- **可访问性**：Dynamic Type、VoiceOver 基础标签
- **错误降级**：无网用精选库；合成失败可重试；权限拒绝仍可系统分享图片（若内存中已有）

## 6. 明确不做或 R&D

| 能力 | 结论 | 原因 | 转入正式版本的门槛 |
|---|---|---|---|
| MVP 短视频贺卡 | OUT（进 P1） | 渲染与体积成本 | 模板管线与导出稳定性达标 |
| 广告变现 | OUT | 与隐私差异化冲突 | 用户明确要求且合规评估 |
| 代发短信 / 读通讯录 | OUT | 合规与隐私 | 不计划 |
| Android MVP | OUT | iOS 优先 | P2 需求验证 |
| 语音祝福 | R&D | 权限与 ASR | 隐私评估通过 |

## 7. 分期摘要

**MVP / P0**：三 Tab（首页 / 创作 / 我的）；关系+AI 文案；静态贺卡合成与保存/分享；精选文案库；收藏与文本模板；本地存储；无广告。

**P1**：自定义照片贴图、动态/短视频贺卡、节日提醒、搜索。

**P2**：会员订阅、更多模板包、Android 评估。

**R&D**：语音祝福、桌面 Widget、智能模板推荐。
