# ADR-001：MVP 核心循环 — 关系 AI 文案 + 静态贺卡

- 状态：已接受（2026-09-03 修订，替代 2026-08-31 纯文字闭环）
- 日期：2026-09-03

## 背景

初版以「祝福短信助手」为竞品，MVP 闭环为文字 AI → 复制/分享。用户改以「大福贺卡」为竞品后，市场验证的是**可分享的视觉贺卡**（含动态视频）。完全对标短视频渲染工程量大；完全忽略贺卡则差异化偏离新竞品。

## 决策

MVP 闭环定为：

**选关系与场景 → AI 生成祝福语 → 套静态贺卡模板 → 保存相册 / 系统分享**

- 差异化：关系导向 + AI 文案 + 无广告不追踪
- 输出形态：仅静态图；动态/短视频贺卡、自定义贴图照片 → P1
- 商业化：MVP 免费；会员 → P2

## 理由

- 静态图可验证「做完能发出去」的贺卡价值，成本可控
- AI + 关系保留相对大福贺卡的内容差异
- 隐私干净对标竞品广告/追踪标签

## 否决条件

- 贺卡合成在目标机型 P95 > 3 秒且无进度反馈
- AI 生成 P95 > 8 秒且无精选库降级
- 未过滤的违规生成内容进入用户可见结果
- 相册权限流程导致无法完成「保存」主路径验收

## 后果

- 正面：形态对齐贺卡品类，同时保留 AI 差异
- 负面：首版视觉丰富度弱于大福动态模板；需靠文案质量与关系入口补偿
