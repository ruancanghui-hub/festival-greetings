# 节日祝福 — 领域词汇表

> 2026-09-03 产品转向后锁定：主路径为「关系+AI 文案 → 静态贺卡 → 分享」。

## 核心实体

**祝福语（Greeting）**：
一条可展示在贺卡上的中文文案，可来自 AI 生成、精选库或用户编辑。
_Avoid_: 短信、消息

**祝福场景（Occasion）**：
用户选祝福的上下文，如春节、生日、圣诞等。
_Avoid_: 节日（Occasion 包含恋爱、婚礼等非公历节日场景）

**关系对象（Recipient）**：
祝福接收方类型（父母、伴侣、朋友等），驱动 AI 语气与模板推荐。
_Avoid_: 联系人（不读取通讯录）

**贺卡模板（Card Template）**：
预置的视觉版式（背景、字体区、装饰），用于合成静态贺卡。
_Avoid_: 主题（Theme 仅指场景分类，不是可渲染资产）

**静态贺卡（Static Card）**：
将祝福语渲染到贺卡模板后得到的可分享图片（PNG/JPG）。MVP 唯一输出形态。
_Avoid_: 动态贺卡、视频贺卡（P1+）

**祝福库（Greeting Library）**：
精选原创文案集合，作 AI 失败或离线时的兜底。
_Avoid_: 模板库（易与贺卡模板混淆）

**收藏（Favorite）**：
对祝福库条目或已生成静态贺卡的书签引用。
_Avoid_: 我的模板

**我的模板（My Template）**：
用户保存的可复用祝福语文本（可编辑）。
_Avoid_: 收藏、贺卡模板

## 用户动作

**生成祝福（Generate）**：
按关系、场景、风格调用 AI 产出祝福语。
_Avoid_: 写祝福

**合成贺卡（Compose Card）**：
将选定祝福语渲染到贺卡模板，生成静态图片。
_Avoid_: 生成视频、导出短视频（MVP 不做）

**分享祝福（Share）**：
通过系统分享面板发送文字或静态贺卡图片；App 不代发短信。
_Avoid_: 发短信

## 系统能力

**相册写入（Photo Library Write）**：
保存静态贺卡到系统相册；MVP 在用户点击「保存」时申请。
_Avoid_: 读取相册（自定义照片贴图为 P1）

**节日提醒（Festival Reminder）**：
节日前本地通知（P1）。
_Avoid_: 推送

**会员（Membership）**：
未来解锁更多贺卡模板与无限 AI；MVP 不启用、无广告。
_Avoid_: VIP
